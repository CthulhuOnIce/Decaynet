Decaynet secrets generator

Generates POSTGRES_PASSWORD, JWT_SECRET, ANON_KEY and SERVICE_ROLE_KEY for the all-in-one Docker stack. Everything happens in this page with your browser's crypto; nothing is sent anywhere. Paste the lines into Portainer (Stack → Environment variables → Advanced mode) or into a .env file.

Keep these private: SERVICE_ROLE_KEY bypasses all access rules. Generate once per site and keep a copy; changing them later requires resetting the database volume.
